# glo

_Gleam Go Transit Schedules_

Making a new [ggts](https://github.com/jasonflorentino/ggts) app to learn [Gleam](https://gleam.run/).

## Setup

You'll need the [Gleam](https://gleam.run/install/) programing language installed.

## Development

### Run the app

Build the client and start the server using 
```
./scripts/dev.sh
```
Ctrl+c to quit

### Commit

Check all packages using
```
./scripts/check.sh
```
